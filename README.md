# xyz

A minimalist and distraction-free video player built with Next.js and Bun.

## Features

- **Spotlight Search**: Fast video search with real-time autocomplete suggestions (`/` shortcut).
- **Focused Cinema Player**: Full-focus screen with clean controls, cinema mode toggle, and instant link copying.
- **Discovery Queue**: Quick access to trending videos and categories (Music, Coding, Lo-Fi, Science, Gaming).
- **Direct Link Support**: Paste any video link to play it immediately.

## Getting Started

```bash
bun install
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Quality & Tests

```bash
bun test
bun run lint
bun run build
```
